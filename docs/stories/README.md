# Historical implementation stories

> **Historical material:** These stories and checklists describe past proposals,
> investigations, or implementation snapshots. They are not current API or
> support documentation. Verify every code/configuration claim against source,
> `project.yml`, and [`docs/STATUS.md`](../STATUS.md) before using a snippet.

Current architecture and ownership are documented in
[`development/ARCHITECTURE.md`](../development/ARCHITECTURE.md). Current setup
and test commands are in [`development/SETUP.md`](../development/SETUP.md) and
[`testing/TESTING.md`](../testing/TESTING.md).

The `01-FOUNDATIONS`, `02-SWIFT-6`, and `03-PARAKEET-UX` directories are
retained as project history. In particular, snippets mentioning removed
`RingBuffer`, old `WhisperEngine`, or proposed FluidAudio APIs must not be
copied into production code.
